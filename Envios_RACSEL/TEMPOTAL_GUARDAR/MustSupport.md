## Definicion de Must Support

Un elemento marcado como Must Support representa una obligacion de capacidad del sistema, no una obligacion universal de presencia en todos los recursos.

### Para creadores de datos (Client)

El sistema debe poder capturar, procesar y enviar el elemento cuando la informacion este disponible.

### Para receptores de datos (Server)

El sistema debe poder recibir, almacenar, interpretar y procesar el elemento sin generar errores por su presencia.

### Interpretacion RACSEL

Cuando un elemento Must Support sea relevante para continuidad asistencial, trazabilidad clinica o seguridad del paciente, su persistencia y disponibilidad para consulta posterior deben considerarse requerimientos de implementacion local segun normativa nacional y acuerdos regionales vigentes.
